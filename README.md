Buenas profee!

Para correr mi proyecto es sencillo pones estos comandos en la terminal:

``python -m venv virtualenv``
#Linux: ``source virtualenv/bin/activate``
#Windows: ``virtualenv\Scripts\activate``
``pip install -r requirements.txt``

Y listo de esa manera automaticamente se deberia de descargar los paquetes y librerias necesarias usadas en el proyecto y para correr el orquestador lo puedes hacer desde visual studio o correr este comando desde la carptea raiz del proyecto:

``python main.py``

O

``python3 main.py``

Y listo eso seria todo

He de decir que hice algo extra en el proyecto que fue un web scrapping para recuperar informacion que antes era obsoleta a ahora sacarle valor a los datos, el web scrapping no fue incluido dentro del orquestador porque sino eso seria gastar una alta cantidad de tiempo cada vez que se corra el orquestador
